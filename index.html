02 · Версии

Одна система — разные задачи

Стабильная сборка для повседневной работы, экспериментальные редакции и отдельное ядро для серверов.

Доступна для скачивания

Runget 1.0 Anythink Anywhere

Первая стабильная версия системы. Полноценный рабочий стол, совместимость с Windows и Android, установка через UEFI или Legacy BIOS.

Скачать ISO Требования

Готова к работе

KDE Plasma, браузер, файловый менеджер, терминал и мультимедиа-кодеки — уже в комплекте.

Три экосистемы

Linux-приложения, Windows через Wine и Android через Andryemu в одном окружении.

Разумные требования

x86_64, от 1 ГБ ОЗУ и 10 ГБ диска. Подходит для старых компьютеров и современных сборок.

Core рядом

Отдельная CLI-редакция для серверов: SSH, APT, Docker и опциональный рабочий стол.

Важно: если в программе Discover предлагается установить Runget 9, не устанавливайте это обновление. Это баг Discover — Runget 9 не существует.

03 · Основа

Сильные стороны Debian

Runget наследует проверенную базу Debian и добавляет совместимость, восстановление систем и собственные утилиты.

Стабильность и безопасность

Строгий подход к обновлениям и проверенные пакеты Debian.

Обновления безопасности — обычно в течение 48 часов.

Огромный выбор пакетов

APT, Flatpak и AppImage открывают доступ к тысячам приложений.

Более 59 000 пакетов в репозиториях Debian.

Простые обновления

Обновление через APT или графические утилиты.

sudo apt update && sudo apt upgrade

Восстановление систем

Runget может использоваться для восстановления Debian/Ubuntu-систем.

GRUB, fstab и сброс пароля root.

Сообщество

Большое сообщество Debian и формирующаяся база Runget.

Инструкции для Debian и Ubuntu применимы напрямую.

Удобство для новичков

Дружественный интерфейс и подсказки для лёгкой адаптации.

Панель задач и меню «Пуск» — как в Windows.

Универсальная совместимость

Три экосистемы одновременно: Linux, Windows и Android.

LibreOffice, 1С через Wine и Telegram через Andryemu.

Лёгкость и скорость

Меньше ресурсов, чем у Windows 10/11 или macOS.

1 ГБ RAM и 10 ГБ диска против 4 ГБ RAM и 64 ГБ для Windows 11.
